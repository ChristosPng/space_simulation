# Space Simulation

A Python-based orbital mechanics and space physics simulation.

## Overview
- Implements gravitational kinematic calculations and body position updating + simple collisions.
- Lightweight written in pure Python.

## How to Run
bash
python main.py

##Controls
Space for pause
UP/DOWN buttons for dt change
Right Click and Hold for spawning new body 
Cycle between bodies using "T"
Increase Mass using "[" and "]"
Increase Radius using "-" and "+"
